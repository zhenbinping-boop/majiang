# 来把麻将

纯前端零依赖的四人麻将小游戏，双击 `index.html` 即可开始。
主打「三分钟一把 · 随时随地开打」——轻量、亲民、简单易上手。

## 玩法
- 标准四人麻将，含吃 / 碰 / 杠 / 听 / 和牌
- 牌河、副露、结算与规则弹窗
- 矢量 SVG 牌面，响应式适配桌面 / 平板 / 手机 / 横屏

## 界面
- **主界面**：清新轻快风（明亮米白 + 暖橙主色）。大主按钮「快速开局」占据视觉中心，
  「继续上局」可回到未打完的对局。
- **入场动画**：数十张麻将字面从四方飞入、洗牌翻转，最后立起拼成「来把麻将」。
  可点击「跳过」，也遵循系统「减弱动态效果」偏好。

## 运行
直接用浏览器打开 `index.html`，无需构建、无需服务器。
