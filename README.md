# 来把麻将

纯前端零依赖的四人麻将小游戏，双击 `index.html` 即可开始。
主打「三分钟一把 · 随时随地开打」——轻量、亲民、简单易上手。

## 玩法
- 标准四人麻将，含吃 / 碰 / 杠 / 听 / 和牌
- 牌河、副露、结算与规则弹窗
- 矢量 SVG 牌面，响应式适配桌面 / 平板 / 手机 / 横屏

## 界面
- **主界面**：一面牌背朝上的**深绿色麻将墙**铺满背景并持续缓缓流动，暖白文字 +
  暖橙主按钮浮于其上。大主按钮「开始游戏」占据视觉中心，「继续上局」可回到未打完的对局。
- **开局转场**：点「开始游戏」后整面墙的牌由中心向外涟漪式翻面（34 种牌面各不相同），
  随后整体从屏幕中心向外放大，平滑推进正式牌桌。遵循系统「减弱动态效果」偏好。

## 运行
直接用浏览器打开 `index.html`，无需构建、无需服务器。
