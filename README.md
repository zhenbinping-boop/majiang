# 中式麻将 · 单机版

纯前端零依赖的四人麻将游戏，双击 `index.html` 即可开始。

## 玩法
- 标准四人麻将，含吃 / 碰 / 杠 / 听 / 和牌
- 牌河、副露、结算与规则弹窗
- 矢量 SVG 牌面，响应式适配桌面 / 平板 / 手机 / 横屏

## 运行
直接用浏览器打开 `index.html`，无需构建、无需服务器。
